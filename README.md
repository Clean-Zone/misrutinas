# MisRutinas (versión web).

Registra tus rutinas y entrenamientos. Funciona sin conexión y se instala en la pantalla de inicio.
Tus datos se guardan solo en tu teléfono (no hay cuentas ni servidor).

## Instalar en iPhone
1. Abre la dirección de la app en **Safari**.
2. Toca el botón **Compartir** y elige **Agregar a pantalla de inicio**.
3. Abre MisRutinas desde el icono. Si quieres avisos de descanso, activa las notificaciones en Perfil.

## Respaldo
En Perfil → Respaldo puedes guardar y restaurar tus datos. En iPhone, si no abres la app durante varias semanas, Safari puede borrar los datos del navegador: haz un respaldo de vez en cuando.

## Publicar en GitHub Pages
Sube el contenido de esta carpeta a un repositorio y activa Settings → Pages → Deploy from a branch (main, carpeta raíz).
Para publicar una versión nueva, cambia `VERSION` en `sw.js` (por ejemplo `mr-v2`) para que los teléfonos actualicen.
